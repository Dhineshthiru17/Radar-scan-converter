Glossary

Terms used throughout this console

Digital Signal Processing — converts raw returns into a display-ready signal

Fast Time Constant — a filter that reduces short-range rain and clutter

Sensitivity Time Control — reduces gain near the radar to limit clutter

Constant False Alarm Rate — adapts the detection threshold to local noise

Moving Target Indication — suppresses returns from stationary objects

Plan Position Indicator — the classic circular sweep radar display

The antenna's reference bearing, used to align azimuth to true north

A network delivery method that streams scan data to many receivers at once

One discrete bearing slice of a full 360° rotation

One discrete distance slice along a radar beam

A learned map of persistent, non-target returns used to suppress them

Separates returns by radial velocity to isolate moving targets

A defined coastline boundary used to suppress or highlight land returns

The baseline receiver noise level against which targets are detected

A cell adjacent to the cell under test, excluded from noise estimation

False returns caused by wave action, strongest in high sea states
